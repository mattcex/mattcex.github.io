# mattcex.github.io

Strona główna konta. Przekierowuje do aplikacji [Lootsy](https://mattcex.github.io/konkursy/)
i udostępnia plik [`.well-known/assetlinks.json`](.well-known/assetlinks.json), który potwierdza,
że aplikacja na Androida `io.github.mattcex.lootsy` i strona należą do tego samego właściciela
(dzięki temu aplikacja otwiera się bez paska adresu przeglądarki).

Plik `.nojekyll` wyłącza Jekylla, żeby katalog `.well-known` był publikowany.
